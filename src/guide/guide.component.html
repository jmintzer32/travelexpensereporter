Do these once. Everything is saved in this browser, so use the same browser on the same computer each time.

  1. 1

    Add your projects

    Projects are how lines get the right Coupa cost code. Either:

    • In 2. Define Trips, open a trip’s Project list and choose + Add a project…. Enter the company code (e.g. 4010), project number, a name you’ll recognize, and the WBS element (travel is usually 01A.021200, already filled in).
    • Or, after generating a report, open the sliders icon in 4. Enter into Coupa → Add projects from cost codes, and paste cost codes from a past Coupa report, one per line, like 4010-Project WBS-12345B1-01A.021200 Main St Tower.
    • Or pick them in Coupa: once the Coupa Filler bookmark is set up (step 3), open a draft report, click the bookmark, go to Cost codes → Add a project, pick the project’s cost code as usual, then click Add to expense site. Pick several before sending if you like.
  2. 2

    Check the Coupa category names

    Same sliders icon. Each category here (Meals, Fuel, Taxi & Ride Share…) is matched to a Coupa Expense Category (Meals - Travel, Rental Car - Fuel…). They’re preset to Coupa’s names; the start of the name is enough. Leave one blank to always pick it yourself in Coupa.

  3. 3

    Add the Coupa Filler to your bookmarks bar

    The Coupa Filler is a bookmark that opens a helper panel on your Coupa page. Nothing gets installed.

    1. Show your bookmarks bar: Ctrl+Shift+B (Mac: ⌘+Shift+B).
    2. Drag this button onto the bookmarks bar:

    Can’t drag it (some work laptops block that)? , then right-click the bookmarks bar → Add page… (Edge: Add favorite), name it Coupa Filler, and paste into the URL box.

    When this site gets an update, the panel says so the next time you paste expenses: click Update now. If Coupa blocks that, replace the bookmark the same way as above. The panel shows its version at the bottom.

  4. 4

    Cost codes: nothing to set up

    The Coupa Filler opens each line’s Account search and types the project’s codes into each field (company code, Project WBS, project number, WBS element), picking the one match. Only if that doesn’t work for you, show it once with Teach.

} @case ('each-time') {

Each trip becomes its own Coupa expense report.

On this site

  1. 1

    Upload your statements

    PDF, CSV, Excel or text exports from your card.

  2. 2

    Define each trip

    Dates, a Business Purpose (Coupa requires one on every line), and the Project. Only fill in WBS Element if it isn’t the project’s usual one. Use + Add Trip for more trips.

  3. 3

    Generate and review

    Check the lines. If one belongs to a different project, change it in the small list under its category.

  4. 4

    Click “Copy for bookmarklet”

    In 4. Enter into Coupa. All trips are copied at once.

In Coupa

  1. 5

    Open the Coupa Filler

    Go to Coupa’s Expenses page and click the Coupa Filler bookmark. A panel opens at the top right. Click in its box, paste (Ctrl+V), and click Load expenses.

  2. 6

    Make the report

    Pick the trip at the top of the panel, then New Coupa report for this trip. It clicks Create and names the report. To add to a report you already started, open it in Coupa and click Use open report instead.

  3. 7

    Fill the lines

    Click Fill next. It adds a line, fills the category, date, amount, description, merchant, business purpose, zip code and cost code, and saves it. Click Fill next again for the next line, or Fill all to do the rest of the trip while you do something else.

    If a cost code couldn’t be set, the line is still saved: the panel’s Cost codes tab lists those lines and the code each one needs. To check lines before they’re saved, untick Save each line in the panel’s Setup tab.

  4. 8

    Receipts and submit

    Attach receipts and submit in Coupa as usual (the filler doesn’t handle receipts). Then pick the next trip in the panel and repeat from step 6.

No bookmark allowed? Use Entry mode in 4. Enter into Coupa: put it beside Coupa and press Enter to copy each field in Coupa’s order.

} @case ('teach') {

Usually you don’t need Teach: the Coupa Filler searches each field of Coupa’s Account search for the project’s codes, which are unique, and picks the one match. Teach is the backup: if a cost code still won’t set (the line shows ✎ on the panel’s Cost codes tab), show it once how you pick a cost code and it repeats that for every project.

Where is the Teach button? In Coupa, not on this site. It’s in the Coupa Filler panel, on the Cost codes tab.
  1. 1

    Open a draft report in Coupa

    Any draft works, including one the filler just created. Teach adds a new line to it, which you can fill or cancel afterwards.

  2. 2

    Click the Coupa Filler bookmark

    If you’ve pasted your expenses, pick a trip that has a project, so the panel can tell you exactly which project to pick.

  3. 3

    Click Teach

    The panel opens a new expense line and Coupa’s Account search window (the magnifier next to Account), then says “I’m watching”.

  4. 4

    Pick the cost code like you always do

    In the Account search: company code (change it if needed) → cost type “Project WBS” → project → WBS element → Coupa’s button to confirm.

  5. 5

    Done

    The panel says “Learned it” and shows the account. The line it opened now has that cost code: click Fill next to use it, or Cancel it in Coupa.

Adding a new project from Coupa

  1. 1

    On the panel’s Cost codes tab, click “Add a project”

    With a draft report open. It opens a line and the Account search, like Teach.

  2. 2

    Pick the project’s cost code and confirm

    Repeat for more projects if you want.

  3. 3

    Click “Add to expense site”

    This site opens in a new tab with the projects added (named after Coupa’s project names). If your browser blocks that, click Copy instead and paste into Add projects from cost codes here. Then cancel the empty line in Coupa.

If the panel says “Nothing changed”, click Teach again and make sure you finish with Coupa’s own confirm button. If lines show up on the Cost codes tab as ✎ set it in Coupa with an “Account” message, check the project’s numbers on this site, then try Re-teach. Either way the lines are already saved; set their Account in Coupa (tick them → Bulk Line Actions → Edit).

Nothing happens when I click the bookmark
Make sure the Coupa tab is the one in front, then click it again. If it still doesn’t open, delete the bookmark and add it again from , step 3. Use Chrome or Edge.
“A newer Coupa Filler is available”
Click Update now in the panel. If it says Coupa blocked the update, replace your bookmark: , step 3. What it learned and your settings are kept either way.
I can’t find Teach
It’s in the panel on your Coupa page, on the Cost codes tab. On this site there’s nothing to teach. .
“Pick the Expense Category in Coupa”
Coupa had no category matching the name in this site’s settings. Pick it in Coupa, click Save there, then Fill next. To stop it happening, fix the name under the sliders icon in 4. Enter into Coupa. The panel’s message lists what Coupa offers.
“A line is open in Coupa with unsaved changes”
Save or cancel that line in Coupa, then click Fill next.
Lines marked ✎ on the Cost codes tab
Their cost code didn’t take, but the lines are saved. Set the Account in Coupa: tick those lines → Bulk Line Actions → Edit. Then check the project’s company code, number and WBS in this site’s settings, and if they’re right, click Re-teach. If it keeps happening, turn off Set cost codes while filling lines on that tab.
My projects or settings disappeared
They’re saved in this browser only. A different computer or browser, a private window, or clearing browsing data starts empty. Paste your cost codes again (sliders icon → Add projects from cost codes). To back up what the filler learned, use Copy setup in the panel’s Setup tab and keep the text somewhere; Import setup puts it back.
A project I picked in Coupa isn’t on this site
Teach only teaches the Coupa Filler, since Coupa and this site can’t see each other’s saved data. To bring a project over, use Add a project on the panel’s Cost codes tab, then Add to expense site. .
